# Ostad CI/CD React Application

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 📖 Overview

This repository contains a **React** application that showcases a simple portfolio website and demonstrates a **GitHub Actions CI/CD pipeline** using a self‑hosted runner. The pipeline automatically builds, tests, and deploys the app whenever code is pushed to the `development` branch.

## ✨ Features
- Modern React stack created with Vite
- Automated linting, testing, and production build via GitHub Actions
- Self‑hosted GitHub Actions runner configuration
- Clean project structure ready for extension

## 🛠️ Getting Started

### Prerequisites
- Node.js **v20+** (recommended) – [download](https://nodejs.org/)
- npm (comes with Node) or Yarn
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/ostad-self-hosted-ci-cd-runner.git
cd ostad-self-hosted-ci-cd-runner

# Install dependencies
npm install   # or `yarn install`
```

### Development Server
```bash
npm run dev   # starts Vite dev server at http://localhost:5173
```

### Build for Production
```bash
npm run build   # outputs static files to the `dist` folder
```

## 🚀 CI/CD Pipeline
The **GitHub Actions** workflow lives in `.github/workflows/ci.yml`. It performs the following steps on each push to the `development` branch:
1. Checks out the code
2. Sets up Node.js environment
3. Installs dependencies
4. Runs linting and tests
5. Builds the production bundle
6. Deploys the `dist` folder (customize the deploy step for your hosting provider)

A **self‑hosted runner** is configured to run these jobs on your own infrastructure. See the repository's `README-self-hosted-runner.md` for detailed setup instructions (or add it later).
